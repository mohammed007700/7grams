# 7 GRAMS: تشغيل التطبيق على GitHub مع حسابات للموظفين

هذا المجلد هو النسخة المستقلة من التطبيق. كل موظف يدخل بإيميله وكلمة مرور يختارها، ويرى فرعه فقط، وما يدخله (ستوك، مبيعات، مهام، صور) يوصل للمدير مباشرة.

أسماء الأزرار في Firebase و GitHub قد تختلف قليلاً عن المكتوب هنا.

## الملفات

| الملف | وظيفته |
|---|---|
| `index.html` | التطبيق كاملاً |
| `firebase-config.js` | بيانات الربط بقاعدة البيانات وإيميل المدير. **تعدّله أنت** |
| `firestore.rules` | قواعد الحماية. **تعدّل فيه الإيميل ثم تلصقه في Firebase** |
| `manifest.webmanifest` و `sw.js` و `icon-*.png` | تجعل التطبيق ينزل على الشاشة الرئيسية بأيقونة |

## الخطوة 1: قاعدة البيانات (Firebase)

1. ادخل https://console.firebase.google.com وأنشئ مشروعاً جديداً (مثلاً `7grams`).
2. من **Build > Authentication** اضغط Get started، ثم فعّل طريقة **Email/Password**.
3. من **Build > Firestore Database** اضغط Create database واختر **Production mode**، واختر أقرب منطقة.
4. افتح ملف `firestore.rules` وغيّر `owner@example.com` إلى إيميلك (بحروف صغيرة). انسخ الملف كله والصقه في تبويب **Rules** في Firestore ثم اضغط **Publish**.
5. من إعدادات المشروع (علامة الترس) > **Your apps** اضغط أيقونة الويب `</>` وسجّل تطبيقاً. ستظهر لك قيم `apiKey` و `authDomain` و `projectId` و `appId`.

## الخطوة 2: ملف الإعدادات

افتح `firebase-config.js` والصق القيم الأربع مكان `PASTE_...`، واكتب إيميلك في `OWNER_EMAIL` (نفس الإيميل الذي كتبته في القواعد).

قيمة `apiKey` ليست سراً، فوجودها في GitHub طبيعي. الحماية تأتي من قواعد Firestore.

## الخطوة 3: الرفع على GitHub

1. أنشئ حساباً في https://github.com ثم مستودعاً جديداً عاماً (Public)، مثلاً `7grams`.
2. ارفع كل ملفات هذا المجلد (Add file > Upload files).
3. من **Settings > Pages** اختر المصدر **Deploy from a branch**، والفرع `main` والمجلد `/ (root)` ثم احفظ.
4. بعد دقيقة أو دقيقتين يظهر رابط التطبيق بهذا الشكل: `https://اسم-حسابك.github.io/7grams/`

## الخطوة 4: السماح للرابط بتسجيل الدخول

في Firebase: **Authentication > Settings > Authorized domains** أضف `اسم-حسابك.github.io`.

## الخطوة 5: أول دخول

1. افتح رابط التطبيق.
2. اكتب إيميلك (إيميل المدير) واختر كلمة مرور واضغط **إنشاء حساب جديد**. ستدخل كمدير.
3. ارفع ملفات المبيعات والتوالف والأسعار وباقي البيانات من جديد. بيانات النسخة السابقة داخل Claude لا تنتقل تلقائياً.

## الخطوة 6: إضافة الموظفين

1. اضغط الثلاث نقاط (⋮) في أعلى التطبيق.
2. في **إضافة موظف** اكتب الاسم والإيميل واختر الفرع والشفت واضغط **إضافة**.
3. لكل موظف زر **دعوة بالإيميل** يفتح تطبيق الإيميل برسالة جاهزة فيها الرابط والخطوات، وزر **نسخ الدعوة** لإرسالها بالواتساب.
4. الموظف يفتح الرابط، يكتب إيميله ويختار كلمة مرور ويضغط **إنشاء حساب جديد**.
5. لتنزيله على الجوال: من قائمة المتصفح يختار **إضافة إلى الشاشة الرئيسية** (Safari على الآيفون، Chrome على الأندرويد).

لجعل شخص مديراً ثانياً اختر له في خانة الفرع **مدير (كل الفروع)**.

## ما يراه الموظف

- فرعه فقط، والأقسام التي تحددها له بعلامات الصح.
- لا يقدر يقرأ بيانات فرع آخر حتى لو حاول تقنياً: المنع في قاعدة البيانات نفسها.
- يدخل الستوك ومبيعات شفته والمهام اليومية وصورها، وتظهر عند المدير مباشرة.

## ملاحظات

- **تحديث التطبيق:** ارفع `index.html` الجديد على GitHub مكان القديم. لا تستبدل `firebase-config.js`.
- **صور المهام** تُحذف تلقائياً بعد 30 يوماً، وتبقى القراءات.
- **نسيان كلمة المرور:** زر "نسيت كلمة المرور" يرسل رابط تغييرها لإيميل الموظف.
- **تقييمات قوقل** ما زالت بإدخال يدوي.
- **التراجع (↶)** يعمل ما دامت الصفحة مفتوحة.
